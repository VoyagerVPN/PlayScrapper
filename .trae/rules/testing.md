# Testing Rules

## Тестируемость
- Каждый модуль должен экспортировать чистые функции для тестирования
- Зависимости должны мокаться через интерфейсы
- Не использовать глобальные состояния

## Перед коммитом
1. `tsc --noEmit` должен проходить
2. `npx knip` не должен находить dead code
3. `npm run lint`

## Debug
- Использовать debug модуль или Logger с уровнями
- Не оставлять временные файлы в репозитории
